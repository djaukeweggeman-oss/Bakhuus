# ’t Bakhuus Duiven — bestelwebsite demo

Een moderne, responsive verkoopdemo voor ’t Bakhuus Duiven met een complete online bestelervaring.

## Functionaliteit

- Responsive homepage en menukaart
- Zoeken, categorieën, favorieten en uitverkochtstatus
- Productopties, sauzen, opmerkingen en aantallen
- Winkelmand met automatische totalen en upselling
- Afhalen/bezorgen, tijdkeuze, klantgegevens en betaalmethode
- Bestelbevestiging zonder echte betaaltransactie

## Lokaal starten

```bash
npm install
npm run dev
```

Open vervolgens [http://localhost:3000](http://localhost:3000).

## Productiebuild

```bash
npm run build
```

De demo gebruikt Next.js, TypeScript en Tailwind CSS. Productgegevens zijn lokaal gestructureerd en kunnen later worden vervangen door een database of CMS.
